# Sistema de Evaluaciones Cristofonía SV

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `logo-cristofonia.png` y `.nojekyll`.
3. En **Settings > Pages**, selecciona la rama principal y la carpeta `/root`.
4. Guarda y espera a que GitHub publique el sitio.

El sistema usa Vue, Tailwind, Font Awesome, html2pdf.js y PDF.js desde CDN. La base de datos actual se guarda en el navegador mediante `localStorage`; usa los botones de respaldo/restauración para trasladar datos entre dispositivos.
